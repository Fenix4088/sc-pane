# Changelog

Versions follow [semantic versioning](https://semver.org). Bump `version` in `.claude-plugin/plugin.json` for every release: users only receive an update when it changes.

## Unreleased

- Internal: `hooks/register.tsx` split into modules (constants, types, store, git, helpers, actions, and one container plus components per pane). No change in behaviour.

## 0.1.0

First public version.

- Commands: `/sc-pane` for the Source Control pane and `/sc-pane-graph` for the Graph pane.
- Source Control pane: changes with line counts, stage, unstage and discard, commit, commit and push, commit and sync, amend and undo.
- Commit messages generated by Claude from the diff, following the repository's recent subjects and commitlint config.
- Fetch, pull, push, publish and sync, with incoming and outgoing commits.
- Branch switching with search, and create, create from, rename, delete and merge.
- Stash, stash with untracked files, stash staged, and apply, pop and drop.
- Graph pane with branch lanes and commit actions: create branch, cherry-pick, revert, checkout and copy hash.
- Commitlint check before committing when the repository has `@commitlint/cli`.
